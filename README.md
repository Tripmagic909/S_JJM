# 忍者じゃじゃ丸くん SG-1000移植

SEGA SG-1000向けの「忍者じゃじゃ丸くん」移植プロジェクト。Z80ソースの参照にMSX版(Jaleco, 1986)を用い、グラフィックはMSX版より豪華にファミコン版寄りの見た目を目指す。

進め方・詳細はマイルストーン計画を参照: [docs/milestones.md](docs/milestones.md)

## 開発環境

- アセンブラ: [pasmo](http://pasmo.speccy.org/) (`apt install pasmo`)
- 逆アセンブラ: `z80dasm` (MSX版ROM解析用)
- 検証ハーネス: `tools/headless/harness.c` — [z80ex](https://github.com/pigmaker57/z80ex)でZ80命令を実行し、簡易TMS9918(VDP)モデルで画面をレンダリングしてPNGを出力する自前のヘッドレステスター。GUI/実機なしでも画面表示を確認できる。
  - MAMEのsg1000ドライバはこの環境のDebianパッケージではカートリッジスロットのデバイスオプションが欠落しており使用不可だったため、この独自ハーネスを採用している。

## ビルド・動作確認

```sh
./build.sh
```

`src/main.asm` を `build/jajamaru.sg` にアセンブルし、ヘッドレスハーネスで実行、`build/frame.png` に画面のスクリーンショットを出力する。

## ディレクトリ構成

- `src/` — SG-1000版のZ80ソース
- `tools/` — ビルド・検証用ツール(ヘッドレスハーネス, PNG変換スクリプト)
- `docs/` — マイルストーン計画、解析メモ、スクリーンショット
- `assets/` — グラフィック/サウンド素材(今後追加)

## 著作権について

MSX版ROM・ファミコン版ROMなどの参照データ自体はリポジトリに含めない。解析結果のメモや構造ドキュメントのみを格納し、グラフィックは新規に描き起こす。
