# 忍者じゃじゃ丸くん SG-1000移植 マイルストーン計画

## 前提・方針

### 方針転換 (M5完了時点)
- **グラフィック**: FC版(忍者じゃじゃ丸くん (J).nes)の実データ(CHR-ROM+PRG-ROM内の
  パレット/オブジェクト定義)を移植する方針に変更。M3では断片的な調査に留まった
  ため、G1以降で全キャラクター/タイルを体系的に調査・移植し直す。
- **ロジック/Z80移植**: 引き続きMSX版ROMを参照する(MSXはZ80、FCは6502のため、
  コードの直接移植ができるのはMSX版のみ。FC版は"挙動・演出"の参考として使う)。
- グラフィックは実装前に必ず候補を提示し、ユーザー承認後にVRAMデータへ反映する。
- 著作権のあるROM/NESファイル自体はリポジトリに含めない。解析メモ・構造ドキュメント
  と、変換済みのSG-1000用データ(TMS9918パレットに変換済み)のみを格納する。
- 開発環境: pasmo (Z80アセンブラ), z80dasm/da65 (逆アセンブラ), 自作ヘッドレス
  ハーネス(tools/headless/harness.c, z80exベース)でスクリーンショット検証。

## マイルストーン一覧

### M0: 開発環境・検証基盤の構築
- ツールチェーン確定・ビルドスクリプト作成
- SG-1000用の最小ROM雛形（VDP初期化・画面を単色表示するだけ）を作成
- MAMEでヘッドレス実行しスクリーンショットで動作確認できる仕組みを整備
- 完了条件: 自作の最小ROMがMAME上のsg1000で起動し、画面がスクリーンショットで確認できる

### M1: MSX版ROM解析
- z80dasmで逆アセンブルし、メインループ／VDP初期化／スプライト管理／マップデータ／入力処理／サウンドドライバの構造を把握してドキュメント化
- グラフィックデータ(パターン・カラーテーブル)の位置を特定し、現状のMSX版タイル/スプライトを画像化して一覧を作る（解析用、リポジトリには構造メモのみ格納）
- 完了条件: 解析メモと現状グラフィック一覧画像を提示

### M2: SG-1000最小骨格の実装 【完了・ユーザー確認待ち】
- VDPを「Screen 1.5」(Graphics IIモード + パターン/カラーテーブルを1バンクに
  集約するハイブリッド設定、詳細は docs/tech_notes/screen1_5.md)で初期化。
  VBlank割り込み、パッド入力読み取りも実装
- MSX版のマップ/挙動を参考に、仮グラフィックでキャラクター1体が8方向移動できる状態を作る
- 完了条件: ヘッドレスハーネスでキャラが動く様子をスクリーンショット(複数フレーム)で確認
  → `docs/screenshots/m2_move_*.png` で確認済み(仮グラフィックの人型スプライトが
    右→下→左→上の順で移動)
- グラフィックの最終品質目標: ユーザー提示のMSX1格闘アクション系タイトル相当の
  密度・階調(空のグラデーション、詳細な背景レイヤー、多色スプライト)を目指す。
  M2は仮グラフィックのままで、実グラフィックはM3で決定する。

### M3: グラフィック方針決定・候補提示 【一区切り】
- じゃじゃ丸本体はユーザー提供のドット絵(赤+白、黒抜き)を採用し実装済み
  (assets/jajamaru_final_16x16.png)
- 敵・背景タイルはFC版ROMの実データ(CHRデータ+PRG-ROM内のパレット/
  オブジェクト定義テーブル)から抽出した候補を採用:
  - assets/enemies/enemy_ghost_fc.png (おばけ、ピンク)
  - assets/enemies/enemy_frog_fc.png (フロッグ、緑)
  - assets/tiles/tile_brick_fc.png (レンガ壁)
- 完了条件: 候補提示→ユーザー承認 → 達成、M4へ進む

### M4: プレイヤーキャラクター実装 【一区切り】
- 左右移動・重力・ジャンプ・地面判定・まきびし投げを実装
- はしご昇降・詳細アニメーションは未実装(M5以降で必要になった時点で追加)
- 完了条件: 操作性がMSX版相当であることを確認 → 基本操作は達成

### M5: 敵キャラクター＆ステージ1実装 【進行中】
- 敵2種(フロッグ・おばけ、M3で確定したFC版データ)をパトロールAIで配置
- まきびしが敵に当たると撃破(一定時間後に復活)、敵が自機に当たると
  自機がスタート位置に戻る、という当たり判定を実装
- 得点・残機・アイテム・複数面のマップは未実装(引き続き対応)
- 完了条件: 1面を通しプレイ可能

## FC版グラフィック移植フェーズ (G1〜G5)
M3で採用したじゃじゃ丸/敵/レンガタイルは断片的な調査の成果だったため、
ここで6502コードとCHR-ROMを体系的に洗い出し、既存のゲームロジック(M2〜M5で
実装済みのScreen 1.5初期化・移動・ジャンプ・まきびし・敵AI・当たり判定)は
そのまま維持しつつ、グラフィックのみFC版データへ本格的に置き換える。

### G1: FC版グラフィック総調査 【次はこれ】
- 6502コード(PRG-ROM)を体系的に追跡し、プレイヤーの全アニメーションフレーム
  (待機・歩行・ジャンプ・まきびし投げ)、敵キャラクター全種、アイテム、
  背景タイル(地面・壁・はしご等)、UI文字のタイル番号・パレット番号の対応を
  一覧化する
- 完了条件: 一覧ドキュメント(docs/msx_analysis/fc_analysis.mdに追記)と、
  発見した全キャラクター/タイルのプレビュー画像を提示

### G2: プレイヤーキャラ全フレーム移植
- 待機・歩行・ジャンプ・まきびし投げ等のアニメーションフレームをFCデータ
  から復元し候補提示
- 完了条件: 候補提示→ユーザー承認

### G3: 敵キャラクター全種移植
- G1で洗い出した敵タイプ全てをFCデータから復元し候補提示
- 完了条件: 候補提示→ユーザー承認

### G4: 背景タイル・ステージレイアウト移植
- 地面・壁・はしご等のタイルをFCデータから復元し候補提示
- 完了条件: 候補提示→ユーザー承認

### G5: SG-1000実装への反映
- 承認されたグラフィックをVRAMパターン/カラーデータとして実装し直す
  (ゲームロジック自体はM2〜M5のものを流用)
- 完了条件: ゲーム画面で全キャラ/タイルが表示され、これまでの動作
  (移動・ジャンプ・まきびし・敵AI・当たり判定)が引き続き機能することを確認

### M6: サウンド実装
- MSX版(AY-8910)の曲・効果音をSG-1000のPSG(SN76489)向けに変換・実装
- 完了条件: BGM/SEがゲーム内で再生される

### M7: 残りステージ全実装
- 全ステージのマップ・敵配置・面クリア/コンティニュー等
- 完了条件: 全ステージ通しプレイ可能

### M8: 総仕上げ
- タイトル画面・デモ・難易度調整・ROM最終検証・バグ修正
- 完了条件: 通しプレイでクリティカルバグなし、ROM確定

## 進め方
各マイルストーン完了時に成果物（コード・スクリーンショット等）を提示し、次に進めるかどうかユーザーが判断する。
